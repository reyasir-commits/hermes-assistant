Privacy Policy

Last updated: October 7, 2026

Hermes Personal Assistant ("the app") is a private application used only by its owner. This policy explains how the app accesses, uses, stores, and shares Google user data.

Data accessed

  • Gmail: read access to messages and permission to create drafts (gmail.readonly, gmail.compose).
  • Google Calendar: read access and permission to create or update events (calendar.readonly, calendar.events).
  • Google Drive: read-only access (drive.readonly).

How data is used

Google user data is used only to provide features the owner directly requests, such as summarizing email, drafting replies, and managing calendar events. Data is not used for advertising, and it is not sold.

Storage

OAuth tokens are stored only on the owner's own computer with access restricted to the owner's user account. The app does not operate any server that stores Google user data.

Sharing

Google user data is not shared with third parties, except that content the owner asks the app to process may be sent to the AI model provider the owner has chosen, solely to complete that request.

Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
