Hermes Personal Assistant

Hermes Personal Assistant is a private, single-user assistant application. It runs on the owner's own computer and helps the owner manage their own Google account data.

What it does

  • Gmail: reads the owner's messages to create summaries and saves reply drafts. It does not send email.
  • Google Calendar: reads the owner's events and adds or updates events at the owner's request.
  • Google Drive: reads file listings and file contents (read-only).

This application is for personal use by its owner only. It is not offered to the public, and no other users can sign up.
